How It Fits Together

A dual-layer design: a native desktop shell, a Python API server and local inference — nothing leaves your machine. 

 Tauri Desktop App
     |  spawns & manages the FastAPI server,
     |  registers global hotkeys, opens the WebView
     v
 FastAPI Server (127.0.0.1:8000)
     |  REST + SSE streaming endpoints
     v
 Ollama (127.0.0.1:11434)
     |  chat / embed / vision inference
     v
 Local resources: SQLite (FTS5), vector store, filesystem, tools

The Tauri shell spawns the Python backend as a child process, polls it until healthy, then loads the React frontend at http://127.0.0.1:8000/ui.
