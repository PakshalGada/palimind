# Chat release — Phase 11 notes

## Highlights

### Chat
- Persistent chat context bar with model, mode, workspace, artifacts, style,
  memory and context controls.
- Empty-state action cards, follow-up chips, collapsed activity and saved drafts.
- Chat memory with chat/project/global scopes and search.
- Continuity panel: catch-up, decisions, action items, open questions, key facts.
- Chat search with jump-to-message.
- Prompt coach, response styles and auto-routing.
- Critic pass and multi-model council backed by local models.

### Workbench
- Right-side Workbench tabs for Artifacts, Browser, Files and Sources.
- Searchable artifact shelf with live status and saved library access.
- Artifact-as-context from chat, shelf and artifact header.
- Browser page → chat handoff.

### Decks and data
- Shared deck plan between preview and PPTX export.
- Designed slide layouts and native PPTX charts.
- Data Mode: profile CSV/XLSX/JSON, natural-language SQL, inline charts,
  cleaned CSV/XLSX export and dashboard artifacts.

### Multimodal and voice
- Clipboard image/text capture.
- Screenshot-to-chat with native capture and browser fallback.
- Hands-free voice conversation loop.
- Global Quick Ask overlay and hotkey.
- Local OCR, audio transcription, image captioning and video-frame tools.

### Trust and release
- Context inspector with redaction preview for emails, tokens and API keys.
- Retention policy and immediate per-chat deletion.
- Local chat/data/export audit log.
- Cross-surface accessibility checks and fixes.
- Smaller initial bundle, lazy-loaded secondary views, zero runtime dependency
  vulnerabilities.
