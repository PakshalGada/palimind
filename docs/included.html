More Capabilities

Beyond the headline features, PaliMind ships with a set of systems that make it feel like a complete AI workbench.

PaliVoice

Speech-to-text with Faster-Whisper and text-to-speech with Kokoro-ONNX — fully offline voice in and out.

Hierarchical Memory

Short-term, mid-term and long-term episodic memory, embedded and retrieved for persistent conversation context.

OpenCode Integration

Shares the OpenCode global auth store and provides a provider proxy for chat models.

Mixture-of-Experts

Planner/worker orchestration that routes work across models based on the task.

Hardware-Aware Fitting

Detects your GPU and RAM, then recommends the models that will actually fit your machine.

Encrypted Secrets

Fernet (AES-128) encryption for stored credentials.

Web Search

DuckDuckGo search and Scrapling page extraction with caching and domain caps.

Reranking

Local cross-encoder reranking for more relevant retrieval results.

File Watcher

Debounced watchdog-based watching that keeps an index fresh as files change.
