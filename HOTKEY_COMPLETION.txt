PROJECT SCOPE
─────────────────────────────────────────────────────────────────────────────
Build a cross-platform hotkey feature that allows users to capture selected 
text from any application with a single hotkey press, select a destination 
Field, and automatically save it to that Field's indexed knowledge base.

✅ Automatic re-indexing
✅ CLI integration (`pm hotkey start`)
✅ No modifications to existing core/ui code
✅ Standalone hotkey module
✅ Testable at each step
✅ Production-ready for MVP demo

QUICK START
─────────────────────────────────────────────────────────────────────────────

1. Install dependencies:
   pip install -e ".[hotkey]"

2. Start the Boardroom UI:
   pm ui
   (Creates Fields for testing)

3. Start hotkey listener (new terminal):
   pm hotkey start

4. Capture text:
   - Copy text anywhere (Ctrl+C or highlight)
   - Press Ctrl+Shift+E
   - Select Field from popup
   - Text automatically saved & indexed

5. Query your captures:
   - Chat in Boardroom UI
   - Ask questions about your captured text
   - Palimind retrieves from .palimind/captures/

LIMITATIONS (MVP)
─────────────────────────────────────────────────────────────────────────────
• Hotkey runs in foreground (no daemon mode yet)
• No capture preview before saving
• No metadata/tags (timestamp only)
• Requires running FastAPI server for indexing
• Linux needs xclip/xsel for clipboard
• Single hotkey (can't have different ones per Field)
• Text-only (no screenshot/audio capture)
