Everything, self-hosted

Three Products. One Platform.

PaliMind bundles three standalone AI products under one unified CLI and desktop UI.

PaliSpace

The core RAG engine. Point it at any folder and it indexes every document into a 4-bit quantized local vector store.

PaliMail

A fully local email client with an AI layer on top. IMAP/SMTP, AI summaries, priority scoring, and smart drafting.

PaliGlance

Screen-aware AI. Captures your screen, extracts text via EasyOCR, and answers contextually about anything visible.

Agent Swarm

Run pm swarm to decompose queries into parallel sub-tasks across multiple agents, synthesized into one report.

Episodic Memory

Every conversation turn is embedded and stored in a global vector store for long-term context retention.

Hardware Cookbook

Detects GPU, VRAM, and RAM, and recommends models that fit from a catalog of 270+ options.

Voice I/O

Local Speech-to-Text via Faster-Whisper and Text-to-Speech via Kokoro-ONNX. No cloud audio APIs.

Web Search

DuckDuckGo search + Scrapling injects live web context into RAG queries or PaliGlance sessions.

Private by default

Email credentials encrypted with Fernet AES-128. All inference on-device via Ollama. No telemetry.

Architecture

Built for power and privacy.

PaliMind uses a dual-layer architecture. A Python/FastAPI backend handles the heavy lifting — RAG, vector search, email syncing, and Ollama integration — ensuring your data stays out of the cloud.

The frontend is a lightweight Electron wrapper that connects to the local API via REST and SSE, giving you a native desktop experience with global hotkeys, without sacrificing privacy or performance.

Get started

PaliMind is yours.

Requires Python 3.10+, Node.js 18+, and Ollama.

$ git clone https://github.com/PakshalGada/palimind.git && cd palimind
$ python -m venv .venv && source .venv/bin/activate
$ pip install -e . && npm install
$ pm ui
