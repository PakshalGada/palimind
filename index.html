Three Products, One Platform
Everything You Need. Nothing in the Cloud.

PaliMind bundles three standalone AI products under one unified CLI and desktop UI.

🗂

PaliSpace Ctrl+Shift+Space

Multimodal RAG workspace — point it at any folder, index every document, and chat with your codebase, research papers, or notes in natural language. Agent swarm, episodic memory, and voice I/O built in.

📧

PaliMail Ctrl+Shift+E

Fully local terminal-first email client with AI-powered triage. IMAP/SMTP sync, encrypted credentials, AI summaries, priority scoring, spam detection, and smart reply drafting — all from your CLI.

👁

PaliVision Ctrl+Shift+V

Screen-aware AI assistant. Captures your screen, runs OCR + vision LLM analysis, and streams contextual answers about whatever is visible — errors, docs, UIs, anything.

Capabilities
Built for Power Users.

Every feature runs locally via Ollama. No API keys. No quotas. No data leaks.

💬

Chat & Agents

Multi-turn chat plus autonomous agents — Researcher, Comparator, Advisor, Document — that plan, retrieve, and synthesize across your files.

🔧

Multimodal RAG

Semantic search over PDF, DOCX, PPTX, XLSX, images, code, and Markdown. Hybrid BM25 + vector retrieval with CrossEncoder reranking.

🧠

Agent Swarm

Multi-agent orchestrator decomposes complex queries into sub-tasks, runs parallel retrieval, and synthesizes a unified report.

📧

Email Assistant

AI summaries, style-matched draft replies, auto-tagging, and spam triage over IMAP/SMTP. Encrypted credentials.

🔍

Deep Research

Multi-step research runs that gather, read, and synthesize sources into a written report with inline citations.

📊

Compare

Point at multiple documents and get structured side-by-side comparisons with per-year parallel retrieval.

💾

Memory

Persistent episodic memory the assistant builds up and recalls across all your conversations. Mid-term summaries + long-term embeddings.

🎤

Voice I/O STT+TTS

Speech-to-Text via Faster-Whisper and Text-to-Speech via Kokoro-ONNX for hands-free interactions.

🔒

Private by Default

Runs on your machine against your own endpoints. No telemetry, no cloud. Credentials encrypted via Fernet AES-128.

Get Started
Up and Running in 5 Minutes.

PaliMind requires Python 3.10+, Node.js 18+, and Ollama.

01

Install Ollama & Pull Models

curl -fsSL https://ollama.com/install.sh | sh
ollama pull nomic-embed-text · ollama pull gemma4:e2b · ollama pull llava

02

Clone & Install

git clone https://github.com/PakshalGada/palimind.git && cd palimind
python -m venv .venv && source .venv/bin/activate
pip install -e . && npm install

03

Launch

pm ui for the full desktop app, or pm chat for headless CLI mode.

04

No GPU? Use Google Colab

Run colab_setup.py on a free Colab GPU runtime — it installs Ollama, pulls models, and tunnels the endpoint to your local PaliMind via LocalTunnel.
